## KB歌词搜索 v4.0.0 — Flutter Material 3 重构版

从 Python (customtkinter) 完全重写为 Flutter Windows 桌面应用，UI 与性能全面升级。

### 功能

- **6 个歌词源并发搜索**：LRCLIB、Lyrics.ovh、酷狗、酷我、网易云、QQ 音乐，结果流式出现，15 秒超时自动跳过
- **两种搜索方式**：手动输入（歌名/歌手/专辑/时长），或选择/拖入音频文件自动读取元数据搜索
- **批量处理**：文件夹一键处理，逐文件进度列表、可取消、结束汇总
- **歌词预览**：时间戳配色高亮，自动/时间轴/纯文本模式，元数据/去时间戳/去翻译选项
- **智能保存**：原子写入（防损坏）、UTF-8 BOM 编码、冲突时 覆盖/自动重命名/跳过、默认保存到歌曲目录
- **Material 3 界面**：浅色/深色/跟随系统主题、紧凑模式、卡片入场动画、骨架屏、选中结果底部操作条

### 安装

下载 `lyrics_fetcher_windows_x64_4.0.0.zip` 解压后运行 `lyrics_fetcher.exe`。

### 注意

- 首次运行自动迁移旧版（Python）设置；歌词默认保存到歌曲所在目录
- 旧版 Python 源码已归档在仓库 `legacy/` 目录（标签 `v3.0.0-python`）
